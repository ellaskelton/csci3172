### Images

All potion bottle images used in this lab were sourced from a single image sheet found on Pinterest. The original image contained multiple potion bottle designs in various colors and styles, which were extracted and used individually for each potion item in the inventory.

* **Source**: [Pinterest - Potion Bottles Image Sheet](https://ca.pinterest.com/pin/5418462046804790/)
* **Author/Creator**: Mihail Feoktistov (as indicated in the Pinterest post)
* **Usage**: The images were used to represent the 20 different potion items in the Mystic Potions Shop inventory management system. Each potion bottle image was renamed to match its corresponding potion name (e.g., healing-potion.png, mana-elixir.png, etc.).
* **Modification**: The original image sheet was split into individual potion bottle images, each representing a different magical potion type in the inventory system. No other modifications were made to the images themselves.


Images were run through https://www.remove.bg/ to remove all background
