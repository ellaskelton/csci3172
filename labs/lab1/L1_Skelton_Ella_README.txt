# CSCI 3172 - Lab 1

This is a simple one-page website about myself. 
The site is fully responsive, follows UX/UI guidelines, and is W3C compliant for both HTML5 and CSS3. 
No CSS frameworks were used - just plain HTML and CSS.
Code also checked with: https://validator.w3.org/nu/#file, and https://jigsaw.w3.org/css-validator/validator. Both pass with no errors!
